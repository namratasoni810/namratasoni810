## 📚 Learning Philosophy

> "Don't just learn the command. **Understand what happens behind it.**"

**Learn → Build → Break → Troubleshoot → Secure → Automate → Repeat**

Every tool I pick up follows that loop. Breaking things in a lab is where the real learning happens — troubleshooting forces you to understand the *why*, not just the *how*. Once I understand it, I secure it. Once it's secure, I automate it. Then I find the next thing to learn.
